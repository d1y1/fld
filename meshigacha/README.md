# めしガチャ

現在地周辺の外食店をリスト表示し、ランダムで今日のごはんを決める Web アプリです。

- スマホ特化 UI（Material Design 3）
- GitHub Pages 向けの静的サイト（ビルド不要）
- 店舗データは [OpenStreetMap](https://www.openstreetmap.org/) / Overpass API（API キー不要）
- 一覧画面で距離・カテゴリを変更可能 / 営業時間外は除外

## 機能

- 現在地検索（半径 500m / 1km / 2km / 3km）
- カテゴリフィルタ（レストラン・カフェなど）
- 食事向きモード（バー・パブ除外・設定で変更可）
- 営業時間外のお店を除外（時間が不明な店は候補に残す）
- 近い店ほど当たりやすい重み付きガチャ演出
- 除外して再抽選 / 履歴 / 結果シェア
- 徒歩ルート・地図・電話・公式サイト（タグがある場合）
- 検索結果キャッシュ / 位置許可済みなら自動検索（設定でオフ可）

## 使い方

1. 「現在地から探す」をタップ
2. 一覧で距離・カテゴリを切り替え
3. 「ガチャる」でランダムに 1 店を選ぶ

## データ精度について

GitHub Pages（ブラウザのみ）では、ホットペッパー / 食べログ等の商用 API を安全に直接呼べません（CORS・APIキー公開の問題）。そのため OpenStreetMap を使っています。

日本では OSM の店舗・営業時間の抜けが多く、精度に限界があります。より高精度な店舗データを使う場合は、ホットペッパー Gourmet API などを **サーバー経由** で繋ぐ必要があります。

# 地方競馬予測

地方競馬（NAR）のデモレースを選び、近走・人気・騎手・体重などから着順イメージと買い目案を表示する Web ツールです。

- スマホ向け UI（[フクコロ / kaiba](https://d1y1.github.io/kaiba/) に近いカードデザイン）
- GitHub Pages 向けの静的サイト（ビルド不要）
- 出走データは当日開催番組に準拠したデモ（馬名・オッズはサンプル）

## 機能

- 本日開催場から競馬場を選択
- レースを選ぶと予測着順・3着以内確率（Harville 近似）をすぐ表示
- 確率 / 期待値 / オッズのメトリクス表示
- 近走・人気・騎手・体重・枠順・安定の項目別スコア
- 単勝・複勝・馬連・ワイド・穴単勝の買い目案
- 結果シェア（Web Share API / クリップボード）
- レースごとの開催日表示

## 使い方

1. 競馬場を選ぶ
2. レースを選ぶ（そのまま予測結果を表示）

## 注意

娯楽・学習用途です。馬券購入の助言ではありません。実際のレース情報は [地方競馬情報サイト](https://www.keiba.go.jp/) などをご確認ください。

ブラウザのみの静的公開のため、公式 API やリアルタイムオッズには接続していません。

## 今後の開発方針（keiba.go.jp CSV）

方針の結論:

- **ページ構成（開催場 → レース一覧 → 予測カード）は、当日の `racelist` / `horselist` / `odds` で組める。**
- **現行スコアをそのまま再現するには、近5走着順が足りない。** 過去の `racelist` + `horselist`（着順入り）を馬名などで突合して作る。
- **騎手スコア**は、CSV の `騎手成績`（例: `1-1-0-1`）から勝率近似に変えるか、ロジックを CSV 項目に合わせて直す。
- **ZIP の取得はローカルで定期実行する。** GitHub Pages（ブラウザ）から keiba.go.jp を直接取らない。取得・展開した CSV をリポジトリ投入または静的アセット化し、サイトはそれを読んで表示・算出する。

対応の目安:

| 画面・算出 | 当日 CSV | 補足 |
| --- | --- | --- |
| 開催場・レース名・発走・距離・馬場 | 可 | `racelist` |
| 馬番・馬名・性齢・騎手・斤量・枠番 | 可 | `horselist` |
| 馬体重・増減 | 可 | `horselist` |
| 単勝／複勝オッズ・人気 | 可 | `odds`（複勝は期待値の分母に使える） |
| 近走5走着順（近走・安定） | 不可（当日単体） | 過去 CSV の突合が必要 |
| 騎手通算勝率 | 不完全 | `騎手成績` からの近似、またはロジック変更 |
| 3着内確率・項目点・買い目 | 派生値 | CSV 生値ではなく、上記入力から自前算出 |

仕様の参照: [データダウンロード機能説明書](https://www.keiba.go.jp/pdf/manual/data_pdf_manual.pdf)

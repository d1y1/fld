# 地方競馬予測

地方競馬（NAR）のデモレースを選び、近走・人気・騎手・体重などから着順イメージと買い目案を表示する Web ツールです。

- スマホ向け UI（Material Design 3 系）
- GitHub Pages 向けの静的サイト（ビルド不要）
- 出走データはサンプル（実開催・実オッズとは非連動）

## 機能

- 大井・川崎・浦和・船橋・門別・盛岡・園田・高知・佐賀・帯広（ばんえい）から競馬場を選択
- レースごとの出馬表表示（人気順・開催日付き）
- スコアリングによる予測着順・3着以内確率（Harville 近似）
- 内訳（近走 / 人気 / 騎手 / 体重 / 枠順 / 安定）
- 単勝・複勝・馬連・ワイド・穴単勝の買い目案
- 結果シェア（Web Share API / クリップボード）

## 使い方

1. 競馬場を選ぶ
2. レースを選ぶ
3. 「このレースを予測する」をタップ

## 注意

娯楽・学習用途です。馬券購入の助言ではありません。実際のレース情報は [地方競馬情報サイト](https://www.keiba.go.jp/) などをご確認ください。

ブラウザのみの静的公開のため、公式 API やリアルタイムオッズには接続していません。
